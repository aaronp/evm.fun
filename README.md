# evm.fun

[Open here](https://aaronp.github.io/evm.fun)

## Run locally

Needs [Bun](https://bun.sh) 1.3.13.

    cd evm-benchmarks
    bun install
    make dev     # playground at http://localhost:5173
    make build   # static site -> packages/web/dist
    make test

Details: [evm-benchmarks/README.md](evm-benchmarks/README.md).
